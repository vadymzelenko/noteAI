# NodeFlow

Минималистичное веб-приложение для управления задачами и заметками с интегрированным ИИ-помощником. Создано с упором на скорость, чистый UX и приватность пользовательских данных.

## Особенности

- **ИИ-ассистент (Bring Your Own Key):** Подключите свой API-ключ для работы с нейросетью. Запросы отправляются напрямую к провайдеру, минуя бэкенд. Ключ хранится локально на устройстве с опциональной привязкой к аккаунту.
- **Умные Email-напоминания:** Для задач с высокой («красной») важностью система автоматически отправляет письмо на почту за 1 час до дедлайна (работает при активной вкладке).
- **Управление жизненным циклом записей:**
  - **Черновики:** Автосохранение незавершенных записей (хранятся 14 дней).
  - **Корзина:** Безопасное удаление с 14-дневным периодом восстановления перед полной очисткой.
- **Организация контента:** Тегирование по категориям, поддержка внутренних ссылок и удобный предпросмотр.
- **Доступность (a11y):** Полная семантическая разметка (WAI-ARIA) и поддержка горячих клавиш.
